# Session Archive: Ladder Scene Direction Trigger Relics & Exit Spawning

- **Session Version**: v4.7
- **Date**: 2026-10-25
- **Context**: Resolving missing Left/Right direction trigger objects in the 3-Ladder Climbing (`UP`) scene after the 15-second trial, ensuring players can safely exit back to the platformer runner without dying to traps.

---

### User Input
The Up direction scene is not showing any Left/Right direction trigger objects even after 15 seconds. Please add that, otherwise the Ladder climbing will not end without the player dying to the traps.

### AI Thinking & Planning Summary
> The user observed that during the 3-Ladder Ascent (`UP` direction scene, `SCENE_LADDER_CLIMB`), no Left or Right direction trigger objects were spawning, even after the 15-second minigame trial period elapsed. Consequently, the only exit path available was either dying to a trap or leaping off the outer lanes, which was neither intuitive nor aligned with the core direction relic mechanics.
>
> **Root Cause Analysis**:
> 1. `LadderItem` previously only supported `type = 0` (Gold Coin) and `type = 1` (Fruit Shield). There was no relic item type defined for the ladder tracks.
> 2. `enterLadderScene()` pre-generated traps and items up to $y = 85\,\text{m}$ using only Coins and Fruit Shields. Even after 15 seconds ($t = 15.0\,\text{s}$, corresponding to $\approx 57\,\text{m}$ of climbing), no direction relics existed anywhere along the pre-generated path.
> 3. The procedural loop `while (ladderGenTopY < ladderPlayerY + 25.0f)` never spawned any direction relics either.
>
> **Implementation Strategy**:
> 1. **Immediate Post-Trial Relic Spawn**:
>    As soon as `scenePlayTime >= SCENE_DIRECTION_COOLDOWN` ($15.0\,\text{s}$) fires and triggers the trial completion announcement, immediately spawn:
>    - A `DIR_LEFT` direction arrow relic on Lane 0 at `ladderPlayerY + 3.8f`.
>    - A `DIR_RIGHT` direction arrow relic on Lane 2 at `ladderPlayerY + 6.8f`.
>    - An additional direction arrow relic on Lane 1 at `ladderPlayerY + 10.2f`.
> 2. **Procedural Relic Streaming**:
>    In the runtime generation loop (`while (ladderGenTopY < ladderPlayerY + 25.0f)`), when `scenePlayTime >= 15.0f`, allocate a 40% probability to spawn `LadderItem` with `type = 2` (Direction Arrow Relic), alternating between `DIR_LEFT` and `DIR_RIGHT`.
> 3. **Item Collision & Scene Return**:
>    When the climber touches a `type = 2` direction arrow relic:
>    - Play `SFX_RELIC` sound.
>    - Set `platformerSavedDir` to the indicated direction (`DIR_LEFT` or `DIR_RIGHT`).
>    - Spawn floating text `"DIRECTION TRIGGERED!\nWARP <<< LEFT"` or `"WARP >>> RIGHT"`.
>    - Call `returnToPlatformerScene(true)`, seamlessly returning the hero to the horizontal runner moving in that direction.
> 4. **Pulsing Neon Arrowhead Rendering**:
>    Render `type = 2` relics using `directionArrowsTexture` and `getDirectionArrowUV()`, scaled with a sinusoidal breathing pulse ($1.35 + 0.15 \sin(5t)$) and tinted with neon cyan (Left) or gold (Right).
> 5. **Parity for Sky-Fall Scene**:
>    Extended identical post-15s direction trigger relic spawning and collection to `SCENE_SKY_FALL` for complete mechanical consistency across all minigame scenes.
> 6. **Outer-Lane Leap Polish**:
>    Leaping left off Lane 0 now explicitly sets `platformerSavedDir = DIR_LEFT`, and leaping right off Lane 2 sets `platformerSavedDir = DIR_RIGHT`.
