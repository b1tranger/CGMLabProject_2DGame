> 2. Removed shell-dependent batch conditions from [`Makefile`](file:///d:/GitHub/UITS/CGMLabProject_2DGame/Makefile), aligning it directly with the standard clean format used across the lab repository.
> 3. Updated [`.gitignore`](file:///d:/GitHub/UITS/CGMLabProject_2DGame/.gitignore) to track [`build/.gitkeep`](file:///d:/GitHub/UITS/CGMLabProject_2DGame/build/.gitkeep) and [`build/glfw3.dll`](file:///d:/GitHub/UITS/CGMLabProject_2DGame/build/glfw3.dll) while ignoring compiled `.exe` and `.o` files. This ensures the output folder and runtime DLL always exist without requiring runtime shell scripts.
