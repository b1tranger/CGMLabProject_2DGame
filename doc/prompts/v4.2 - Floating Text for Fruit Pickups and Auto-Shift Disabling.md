### AI Thinking & Planning Summary
> **1. Core Question Analysis & Source Investigation**:
> - *Question 1: Does collecting the fruit-like objects trigger a direction change?*
>   Yes. In [`src/main.cpp`](/src/main.cpp) (section 6), the floating fruit-like entities represent `DirectionRelic` objects. When the player hitbox intersects them, `relicsTriggered++`, `audioMgr.play(SFX_RELIC)` is executed, and `triggerRandomDirectionShift("MYSTERY RELIC")` is called to force an immediate warp in runner traversal direction (`DIR_RIGHT`, `DIR_LEFT`, `DIR_UP`, or `DIR_DOWN`) while altering environmental biome tints.
> - *Question 2: What are the perceived "invisible pickups happening at random"?*
>   Deep-dive analysis of the game loop revealed that an autonomous timer was running concurrently in [`src/main.cpp`](/src/main.cpp):
>   ```cpp
>   directionSwitchTimer -= deltaTime;
>   if (directionSwitchTimer <= 0.0f) {
>       triggerRandomDirectionShift("AUTONOMOUS SHIFT");
>   }
>   ```
>   Every $6.5\,\text{s}$, this timer expired and called `triggerRandomDirectionShift("AUTONOMOUS SHIFT")`, which randomly chose a fruit icon (`fruitType = std::rand() % 4`), played the warp chime (`SFX_SHIFT`), flashed the screen, and displayed a corner notification featuring the fruit icon. To the player running through the world, this unexpected chime, screen flash, and fruit notification appeared as if an invisible fruit item had been touched without being on screen.
>
> **2. Technical Solution & System Design**:
> - **World-Space Floating Text Engine**:
>   - Extended [`Renderer::drawText`](/src/Renderer.cpp) to accept an optional `const glm::mat4& view` transformation matrix (defaulting to identity).
>   - In screen-space UI mode, passing `orthoUI` with the default identity view renders directly to pixel coordinates.
>   - In world-space mode, passing camera `view` and `projection` transforms text coordinates $(X, Y)$ into real game-world units, smoothly locked to world entities and tracked by the scrolling camera.
>   - Created a dynamic floating text queue:
>     ```cpp
>     struct FloatingText {
>         std::string text;
>         glm::vec2 pos;
>         glm::vec4 color;
>         float charW, charH;
>         float timer, maxTime;
>         float riseSpeed;
>     };
>     ```
>   - Centered text alignment formula: $X_{\text{start}} = X_{\text{pos}} - (N_{\text{chars}} \times \text{charW} \times 0.5)$.
>   - Smooth vertical rise and alpha fade formula: $\alpha = \min\left(1.0, \frac{\text{timer}}{\text{maxTime} \times 0.35}\right)$, $Y_{\text{pos}}(t) = Y_0 + v_{\text{rise}} \cdot \Delta t$.
> - **Visual Feedback for Pickups**:
>   - When collecting Mystery Fruit Relics: Spawns cyan/teal world text directly over the relic:
>     ```text
>     RELIC COLLECTED!
>     WARP >>> RIGHT (or <<< LEFT, ^^^ ASCEND, vvv DESCEND)
>     ```
>   - When collecting Gold Coins: Spawns golden floating text:
>     ```text
>     +50
>     ```
> - **Invisible Pickups Resolution**:
>   - Set `autoShiftEnabled = false;` by default so random timer-based autonomous shifts are turned off.
>   - Direction shifts now occur **exclusively upon picking up visible Mystery Fruit Relics**.
>   - Added a live toggle (`T` key) and a readout in the `ESC` Pause Menu (`[T] AUTO SHIFTS: [DISABLED (RELICS ONLY) / ENABLED (TIMER + RELICS)]`) so players who enjoy autonomous chaotic shifts can re-enable them at will.
