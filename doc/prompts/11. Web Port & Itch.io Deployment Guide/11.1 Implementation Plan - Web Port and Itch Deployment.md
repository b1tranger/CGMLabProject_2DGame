# Implementation Plan: Web Port & itch.io Deployment

- **Session**: `11. Web Port & Itch.io Deployment Guide`
- **Target Guide**: [`/doc/WEB_PORT_AND_ITCH_GUIDE.md`](/doc/WEB_PORT_AND_ITCH_GUIDE.md)
- **Target Artifacts**: [`/shell_minimal.html`](/shell_minimal.html), [`/build_web.bat`](/build_web.bat), [`/Makefile`](/Makefile)

---

## 1. Objectives
1. Provide an exhaustive, technically rigorous, step-by-step architectural guide explaining how to turn **The Wenderer** (C++17, GLFW, OpenGL 3.3 Core, GLAD, WinMM/MCI, Windows Media Foundation) into a WebAssembly (Wasm) + WebGL 2.0 browser game.
2. Provide complete instructions on compiling, configuring, testing, packaging, and publishing the game on [itch.io](https://itch.io) as a browser-playable HTML5 title.
3. Supply concrete code modifications (`#ifdef __EMSCRIPTEN__`) for the main loop, shader adaptation, Web Audio bridge, virtual filesystem, and persistent browser storage.
4. Provide ready-to-run automation scripts (`build_web.bat`, `shell_minimal.html`, `Makefile` targets) to streamline deployment.

---

## 2. Key Architecture Milestones

### Milestone 1: Toolchain & Build System Integration
- Install and configure Emscripten SDK (`emsdk`).
- Create `build_web.bat` with optimized flags (`-O3`, `-sUSE_GLFW=3`, `-sMIN_WEBGL_VERSION=2`, `-sALLOW_MEMORY_GROWTH=1`, `--preload-file assets`).
- Add `web` and `package-web` targets to [`/Makefile`](/Makefile).

### Milestone 2: Main Loop Asynchronous Refactoring
- Decouple the blocking `while (!glfwWindowShouldClose)` desktop loop in [`/src/main.cpp`](/src/main.cpp) into a discrete `mainLoopTick()` function.
- Register `mainLoopTick` with `emscripten_set_main_loop()` when compiling under `__EMSCRIPTEN__`.

### Milestone 3: Graphics & Shader Migration
- WebGL 2.0 (`<GLES3/gl3.h>`) integration in [`/src/Renderer.cpp`](/src/Renderer.cpp) without requiring desktop GLAD.
- Introduce `#version 300 es` shader definitions with `precision highp float;` qualifiers for fragment calculations.

### Milestone 4: Audio & Storage Web Bridges
- Implement lightweight JavaScript bridges via `EM_JS` in [`/src/Audio.cpp`](/src/Audio.cpp) for HTML5 / Web Audio execution.
- Map high score records (`score_record.txt`) to `localStorage` via `EM_JS`.

### Milestone 5: Itch.io Packaging & Deployment
- Supply responsive, pixel-crisp `shell_minimal.html` template.
- Document ZIP packaging rules (`index.html` at root).
- Document itch.io project dashboard configuration (Kind of Project = HTML, Viewport 1024x720, Fullscreen button enabled).
